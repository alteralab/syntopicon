하나의 질문: **데이터를 프로그램으로 만들어 내는 일은 무엇이고 왜 하는가.**

## 두 낱말의 경계

- 절이 여는 자리 — **컴퓨트·인재와 함께 데이터는 AI의 가장 어려운 난제다. 데이터를 프로그램으로
  생성할 수 있게 되는 것은 산업 전체의 오랜 목표였다. 흔히 쓰이는 두 프로세스가 데이터 증강(data
  augmentation)과 데이터 합성(data synthesis)이다** (8장, p.380).[^huyen2025]
  - **데이터 증강은 기존 데이터(진짜인 것)에서 새 데이터를 만든다. 예컨대 고양이의 진짜 이미지가
    주어지면 그것을 뒤집어 같은 고양이의 새 이미지를 만들 수 있다** (8장, p.380).[^huyen2025]
    - 각주 — **내 책 『Designing Machine Learning Systems』는 4장에서 데이터 증강을 논한다** (8장,
      p.380 각주 8).[^huyen2025]
  - **데이터 합성은 진짜 데이터의 속성을 흉내 내는 데이터를 생성한다. 예컨대 마우스가 웹 페이지를
    가로질러 움직이는 방식을 시뮬레이션해 봇의 움직임이 어떻게 보일지에 대한 데이터를 생성할 수
    있다** (8장, p.380).[^huyen2025]
- 저자가 낱말을 합치는 이유 — **다시 말해 증강된 데이터는 진짜 데이터에서 파생되는 반면 합성 데이터
  (synthetic data)는 진짜가 아니다. 그러나 증강과 합성 양쪽의 목표가 데이터 생성을 자동화하는 것이라
  두 용어가 때때로 서로 바꿔 쓰인다. 이 장에서 나는 흔히 데이터 합성으로 둘 다를 가리키겠다** (8장,
  p.380).[^huyen2025]

## 소프트웨어 테스트에서 온 계보

- **인공적으로 생성된 데이터는 소프트웨어 엔지니어링에서 긴 역사를 갖는다. 원래는 테스트 목적으로
  가짜 데이터를 생성하는 데 쓰였다. 예컨대 Faker와 Chance 같은 라이브러리는 이름·주소·전화번호·
  이메일 주소 같은 단순한 형식의 데이터를 생성하게 해 준다. 배송 주소를 파싱하는 프로그램을
  만들었다고 하자. 가짜 데이터 생성기를 써서 서로 다른 형식의 여러 나라와 주의 주소를 생성해 프로그램이
  그것들을 다 파싱할 수 있는지 확인할 수 있다** (8장, p.380).[^huyen2025]
- 무엇이 바뀌었나 — **AI가 사람이 생성한 것과 구별할 수 없는 데이터를 생성할 수 있게 되면서, 의사
  소견서·계약서·재무제표·제품 설명·이미지·비디오 광고 등 훨씬 정교한 데이터를 합성하는 것이 가능해졌다.
  이는 데이터 생성을 더 쉽게 만들고 더 많은 합성 데이터 유스케이스를 가능하게 한다** (8장,
  pp.380–381).[^huyen2025]

## 합성이 사람 데이터를 대체하지는 않는다

- **합성 데이터가 사람이 생성한 데이터에 대한 압박을 크게 줄이겠다고 약속하지만, 합성 데이터가 사람
  데이터를 완전히 대체하지는 않는다. 393쪽 "Limitations to AI-generated data"에서 논하듯 많은
  유스케이스에서 사람이 생성한 데이터와 AI가 생성한 데이터를 섞는 것이 흔히 최선의 가치를 낸다**
  (8장, p.381).[^huyen2025] 그 한계는
  [AI 생성 데이터의 한계](../concepts/limitations-of-ai-generated-data.md)에 있다.

## 합성하는 다섯 이유

- **합성 데이터는 여러 이유로 매력적이다. 데이터를 합성해 수량·커버리지·품질이라는 황금 데이터 삼총사를
  개선할 수 있다. 프라이버시 우려를 완화하고 모델을 증류하려고 데이터를 합성할 수도 있다** (8장,
  p.381).[^huyen2025]
- **To increase data quantity** — **데이터 합성의 가장 큰 이유는 규모 있게 데이터를 생산하게 해 준다는
  것으로, AI 모델을 훈련하고 테스트할 풍부한 데이터 공급을 약속한다. 이론상 더 많은 데이터는 모델이
  넓은 범위의 과제에 일반화하도록 돕는다. 이는 실제 데이터가 희소하거나 얻기 어려운 곳에서 특히
  유용한데, 드문 기상 조건의 데이터, 심해 탐사 데이터, 자율주행차 사고를 포함하는 데이터 같은
  것이다** (8장, p.381).[^huyen2025]
- **To increase data coverage** — **모델 성능을 개선하거나 모델이 특정 행동을 표현하게 하려고 표적화된
  특성을 가진 데이터를 생성할 수 있다. 예컨대 아주 짧은 텍스트나 아주 긴 텍스트를 생성할 수 있다.
  유해성 탐지 모델을 위해 유해한 표현을 담은 대화를 만들 수 있다. 반대로 실제 데이터가 유해하면 안전한
  데이터를 합성할 수 있다. 적대적 예제(adversarial examples)를 합성하는 데 AI를 쓰는 것이 특히 흔하다.
  클래스 불균형의 난제를 다루려고 드문 클래스의 데이터를 생성하는 것도 가능하다. "TrueTeacher"에서
  기술된 대로 Gekhman et al.(2022)은 LLM을 써서 사실적으로 일관되지 않은 요약을 생성한 뒤 그것으로 사실
  비일관성을 탐지하는 모델을 훈련했다** (8장, p.381).[^huyen2025]
  - **논문 "Discovering Language Model Behaviors with Model-Written Evaluations"(Perez et al.,
    2022)에서 Anthropic은 성격 특성·정치적 견해·윤리적 입장·사회적 편향을 포함해 154가지 서로 다른 AI
    행동을 시험할 수 있는 특정 데이터셋을 생성하는 다양한 데이터 합성 기법을 논했다. 그들은 LM(언어
    모델) 생성 데이터셋과 사람 생성 데이터셋의 정면 비교에서 이렇게 발견했다** (8장, p.381):[^huyen2025]

    > LM-written datasets approach the quality of human-written ones, sometimes even exceeding them.

- **To increase data quality** — **합성 데이터가 흔히 사람이 생성한 데이터보다 품질이 낮다는 것이 통념
  이지만, 때로는 그 반대가 참일 수 있다** (8장, p.382). 저자가 기울임으로 강조한
  문장이다 (8장, p.382):[^huyen2025]

  > *Sometimes, humans might have fundamental limitations that cause human-generated data to be of
  > lower quality than AI-generated data.*

  **한 예가 앞서 논한 도구 사용 데이터다 — 사람과 AI는 근본적으로 다른 작동 방식과 도구 선호를 갖는다.
  또 다른 예는 복잡한 수학 문제 생성인데, AI는 평균적 인간 전문가가 떠올릴 수 있는 것보다 훨씬 복잡한
  문제를 생성할 수 있다** (8장, p.382).[^huyen2025]
  - 각주 — **본문에 넣지 않은 명백한 예 하나는 AI가 생성한 콘텐츠를 탐지하는 모델을 훈련하고 싶을
    때다. 훈련 예제로 AI 생성 콘텐츠가 필요하다** (8장, p.382 각주 9).[^huyen2025]
  - 선호 데이터 쪽 — **어떤 팀은 선호 데이터를 생성하는 데도 AI를 선호한다. 개인 각각은 자기 선호에서
    어느 정도 일관될 수 있지만, 사람마다의 성능은 각자의 선호뿐 아니라 기분과 동기에도 영향받아 크게
    다른 경향이 있다. 반대로 AI가 생성한 선호 평정은 훨씬 더 일관되고 신뢰할 만할 수 있다** (8장,
    p.382).[^huyen2025]
- **To mitigate privacy concerns** — **합성 데이터는 프라이버시 우려 때문에 사람이 생성한 데이터를 쓸
  수 없는 유스케이스에서 흔히 유일한 선택지다. 예컨대 의료에서는 법제가 실제 환자 기록으로 모델을
  훈련하는 것을 어렵게, 불가능하지는 않더라도, 만들기 때문에 민감 정보를 담지 않은 합성 환자 기록을
  생성할 수 있다. 보험에서는 민감한 개인·금융 정보를 담은 실제 청구 대신 합성 청구를 쓸 수 있다**
  (8장, p.382).[^huyen2025]
- **To distill models** — **때때로 다른 모델의 행동을 흉내 내도록 모델을 훈련하고 싶을 수 있다. 목표는
  흔히 원본 모델과 비슷한 성능을 가진 더 싸고/또는 더 빠른 모델(증류된 모델)을 만드는 것이다. 이는
  원본 모델이 생성한 데이터로 증류된 모델을 훈련해 이뤄진다** (8장, p.382).[^huyen2025] 그 갈래는
  [모델 증류](../concepts/model-distillation.md)에 있다.
- 절을 닫는 말 — **이것은 사람들이 데이터 합성으로 돌아서는 많은 이유 중 다섯 가지일 뿐이다. 부정할 수
  없는 매력 때문에 더 많은 모델이 합성 데이터로 훈련되고 있고 데이터를 합성하는 더 많은 기법이 개발되고
  있다** (8장, p.382).[^huyen2025]
