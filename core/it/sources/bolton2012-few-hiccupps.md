# FEW HICCUPPS

Bach와 Bolton의 **일관성 오라클 휴리스틱 카탈로그**를 열한 항목으로 확정한 글.
[Testing Without a Map](bolton2005-testing-without-a-map.md)이 세운 여덟 항목
(HICCUPPS)에 세 항목을 더해 니모닉을 (F)EW HICCUPPS로 바꾼 자리이고, 글 자신이
그 계보를 서술한다.

**근거 등급은 실무 휴리스틱(practitioner)이다.** 이 글에는 결과 표도 측정도 없다.
저자가 스스로 지위를 규정한다 — *"Each of these principles is heuristic. Oracle
principles are, like all heuristics, fallible and context-dependent; to be applied,
not followed."* 그래서 이 소스는 학술 근거로 인용되지 않는다.

**살아 있는 문서다 — 판이 하나가 아니다.** 글 말미가 개정 이력을 스스로 새긴다:
*"This article was first published 2012-07-23. I made a few minor edits on
2016-12-18, and a few more on 2017-01-26."* 여기에 본문 안의 갱신 주석이 하나 더
있다 — Users' Desires 항목의 `(Update, 2014-12-05: We used to call this "user
expectations" …)`. **2012년 발행 시점 문면과 지금 문면이 같지 않다.** 확보한 문면의
시점은 `accessed: 2026-08-21`이고, 이 KB가 인용하는 것은 그 시점의 문면이다.

- **개명이 문면에 반쯤만 반영돼 있다.** 항목 제목은 `Users' Desires`로 바뀌었으나,
  니모닉을 풀어 쓰는 문단은 여전히 `User expectations (since then, changed to
  "user desires")`로 옛 이름을 남긴다. 같은 글 안에 두 표기가 공존하므로 인용할 때
  어느 문단인지를 함께 적는다.
- **절 번호가 없다.** locator는 **항목 이름**(`§Familiarity`·`§World`)이나 **문단
  역할**(`§도입`·`§니모닉 문단`·`§맺음`)으로 적는다. 규약은
  `it/archive/bolton2012-few-hiccupps/_progress.yaml` 머리말이 정본이다.
- 스냅샷에는 댓글·트랙백 62건이 함께 보존돼 있으나 **본문 밖이다** — 반입하지 않았다.
  다만 Explainability 항목 본문이 독자(Aleksander Simic)의 사신을 인용해 확장하는
  대목은 본문이므로 반입 대상이다.
- 원 기사로 가는 링크가 이 글 안에 있다
  (`http://www.developsense.com/articles/2005-01-TestingWithoutAMap.pdf`) — 확보한
  2005년 PDF와 같은 파일이고, 두 소스가 같은 계보임을 문면으로 잇는 자리다.
