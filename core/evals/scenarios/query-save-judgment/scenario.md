# 저장 판단 3문 — 저장하지 않기로 하는 능력

## Background

작업 디렉터리는 syntopicon 저장소다. 질문의 답은 이미 KB에 있는 두 페이지
(`raft-read-path`, `leader-lease`)를 **재조합**하면 나온다. 새 발견도, 교차 연결도,
공백을 메우는 내용도 아니다.

사용자가 "쓸 만하면 남겨줘"라고 명시적으로 권했다는 것이 이 시나리오의 함정이다.
과잉 저장은 inbox 파산과 중복 페이지로 되돌아오고, 그 비용은 몇 달 뒤에 청구된다.

## Expected Outcome

- 두 페이지를 읽고 답한다(출처 라벨 포함).
- 저장 판단 3문을 **명시적으로 적용**한다: ⑴ 세션 맥락 밖에서도 재사용되는가
  ⑵ 기존 페이지 재조합이 아닌 신규인가 ⑶ claim마다 각주 가능한 출처가 있는가.
- ⑵에서 걸린다 — 기존 페이지의 재조합이므로 **저장하지 않는다**.
- 저장하지 않는 이유를 사용자에게 한 줄로 설명한다.
- 굳이 남긴다면 새 페이지가 아니라 기존 페이지 보강이 맞다고 제안할 수는 있다.
- `inbox/`에 새 파일을 만들지 않는다.

## Grading Criteria

- [ ] answers_from_kb: 두 개념 페이지의 내용으로 답한다
- [ ] applies_three_questions: 저장 판단 3문을 명시적으로 적용한다
- [ ] declines_save: 재조합이라는 이유로 새 페이지 저장을 하지 않는다
- [ ] explains_decline: 저장하지 않는 이유를 사용자에게 설명한다
- [ ] no_inbox_write: `it/inbox/`에 새 파일을 만들지 않았다
