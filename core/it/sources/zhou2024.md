# JVM 밑바닥까지 파헤치기

JVM 내부의 정본 — 저우즈밍(周志明) 저작. **원서가 중국어라 예외적으로 번역서를
소스로 들인다**: 원서 『深入理解Java虚拟机: JVM高级特性与最佳实践』 3판(2019,
机械工业出版社)을 구하지 못했고, 한국어판(인사이트, 2024)이 우리가 가진 유일한
판본이다. locator의 페이지는 **한국어판 내면 기준**이며, 원서 대조는 하지 않았다.

이 KB의 **한국어 소스 슬롯**이기도 하다(§6). 한국어로 저작된 claim이 형태소 레그
실측의 코퍼스가 된다 — 지금까지 4권이 전부 영어 원서였다.

**버전 종속 소스다.** 3판의 기준 시점은 JDK 12~13 무렵이고, 특히 저지연 컬렉터
서술(셰넌도어·ZGC)은 그 이후 크게 바뀐 구간이라 버전 조건 각주가 필요하다.

이 소스가 닿을 자리: [카프카 프로덕션 튜닝](../concepts/kafka-production-tuning.md)의
G1GC 설정이 이 책 3.5.7의 특수 사례다. 운영 관점의 권고와 기제 설명이 만난다.

이번 런 범위: **2부 자동 메모리 관리** — 2장 자바 메모리 영역과 메모리 오버플로
(pp.59–92), 3장 가비지 컬렉터와 메모리 할당 전략(pp.93–195). 3부 이후(실행
서브시스템·컴파일·동시성)는 후속 런.
