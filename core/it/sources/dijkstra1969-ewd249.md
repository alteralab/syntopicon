# EWD249 Notes on Structured Programming

Dijkstra의 구조적 프로그래밍 각서. **"프로그램 테스팅은 결함의 존재를 보이는 데
쓸 수 있을 뿐, 결함의 부재를 보이는 데는 결코 쓸 수 없다"의 전체형 원전**이고,
이 KB가 이 소스에서 증류한 것은 그 한 구절(인쇄 7쪽)뿐이다 — 나머지 전문은
스냅샷으로만 보존한다.

**판이 둘이라 날짜가 둘이다.** 확보본은 겉표지가 `T.H.-Report 70-WSK-03 ·
Second edition April 1970`이고, 그 다음 속표지(PDF 2쪽)가 `EWD249 / NOTES ON
STRUCTURED PROGRAMMING / by prof.dr.Edsger W.Dijkstra / August 1969`다.
`issued`는 저작 시점인 1969년 8월이고, `edition: 2`와 보고서 번호는 확보한 인쇄
판이다. 이 구분이 실제로 하중을 받는다 — 같은 명제의 경구형이 1969년 10월 로마
NATO 회의에서 나오므로, 선후 판정이 이 두 날짜에 걸린다.

**스캔본이다.** snapshot.py 판정은 `scanned`(신뢰도 0.95, OCR 필요 88/88쪽)이고
텍스트 레이어가 없다 — `pdftotext`가 88바이트만 낸다. 그래서 이 소스의 직인용은
쪽 이미지 육안 판독으로만 한다(`pdftoppm`). 기계 추출 대조는 불가능하고, 인용
구절은 훼손 없는 구간에서만 뜬다.

**쪽 번호는 인쇄 쪽(쪽머리 `EWD249 - n`)이 정본이고 PDF 쪽수와 4만큼 어긋난다** —
PDF 5쪽 = 인쇄 1쪽, PDF 11쪽 = 인쇄 7쪽. 인쇄 쪽은 0쪽("To my reader")부터
84쪽까지다.
