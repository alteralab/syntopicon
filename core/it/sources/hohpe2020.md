# hohpe2020

그레고어 호페의 아키텍트 역할·조직·변환 에세이집(초판 2020-04-07, 추천사 둘 — Simon Brown·HSBC 최고
아키텍트). 6부 41장 — I부 아키텍트(1~7장: 엘리베이터·영화배우 아키텍트·1차 도함수·엔터프라이즈
아키텍트·세 다리·결정·질문), II부 아키텍처(8~17장: 결정으로서의 아키텍처·옵션 판매·시스템은 완벽·
코드·좀비·기계의 일·버전 관리·A4·평평한 IT·2단계 커밋), III부 소통(18~25장: 설명·해적선·바쁜 독자·
강조·다이어그램 주도 설계·선 긋기·몽타주·협업), IV부 조직(26~32장: 역공학·통제의 환상·건축·암시장·
확장·느린 혼돈·인셉션 거버넌스), V부 변환(33~40장: 고통·변화 이끌기·속도의 경제·무한 루프·가짜 IT·
돈으로 못 사는 문화·대기행렬·4차원), VI부 에필로그(41장).

- 이 KB에서 맡는 자리는 **아키텍트 역할·조직·변환의 에세이 원전(L2)**이다 — 장당 6~12쪽의 독립 에세이
  41편이고 부 단위로 묶어 **일곱 런에 전권을 반입했다**(추천사 둘·서문·1~41장·부 도비라 여섯 전부).
  [hohpe2004](hohpe2004.md)와 같은 저자이고, [harmellaw2024](harmellaw2024.md)(의사결정 실천)·
  newman2021(조직·아키텍트 역할)·ford2022(진화·거버넌스)와 정면으로 교차한다.
- **L1 개념 페이지와 닿는 접점이 넷**이고 모두 원전 정박을 먼저 한 뒤 이 책이 더하는 것만 담았다 —
  9장 옵션 가치 · 10장 시스템 사고 · 17장 2단계 커밋과 보상 · **39장 대기행렬**(리틀의 결과를
  `T = N/λ`로, M/M/1 평균 대기 수를 `ρ/(1 − ρ)`로 적는다. 정본은 기존 리틀의 법칙·응답 시간과
  처리량·개방/폐쇄 부하 모델 페이지다).
- **이 책이 이 KB에 처음 들여온 이름들**: 대화 패턴(Conversation Patterns, 17장 — 저자 자신의 2004년
  카탈로그에 없다) · 인셉션을 통한 거버넌스(32장) · 속도의 경제 대 규모의 경제(35장) · 스택 오류
  (37장) · HiPPO(38장) · 혁신가의 딜레마(38장) · PARC 분류(38장) · 화물 숭배(34장).
- **첫 원전을 이 책으로 삼은 자리**가 여럿이라 미반입 원전 후보가 남는다 — 실물 옵션과 블랙-숄즈(9장),
  와인버그·메도스의 시스템 사고(10장), 저자 자신의 IEEE Software 2005 글(17장 재수록), 대화 패턴
  카탈로그(17장), 라이너트슨 *The Principles of Product Development Flow*(35장), 리스
  *The Lean Startup*(36장), 크리스텐슨 *The Innovator's Dilemma*(38장), 로버츠 *The Modern Firm*
  (31·38장), 클라인록 *Queueing Systems*(39장), 스포티파이 팀 모형(36장).
- **긴장 요지**: 35장 속도의 경제는 뉴먼의 독립 배포·ford2022의 진화와 **같은 결론에 다른 층위의
  근거**를 댄다(그쪽은 기계 구조, 이쪽은 예산 절차와 배치 크기와 조율 회의) — 겨루지 않는다. 27장
  통제의 환상과 harmellaw의 위계 탈중앙화는 **같은 진단에 다른 처방**이고, 29장 암시장과 오프그리드
  결정은 **형태가 같고 우회 대상이 다르다**. **`contradicts`를 건 쌍은 하나도 없다.**
- **저자의 오식 하나** — 26장이 시스템 사고를 9장이라 적는다(실제로는 10장). 그 페이지 각주에 적었고
  본문에서는 장 번호를 피했다.
- **코드 펜스가 한 줄도 없다.** 이 책에는 코드 목록도 표도 없고, 번호 붙은 도판은 장마다 드물게 있다.
  **장 도비라 마흔하나는 전부 만평이고 작가 이름이 붙지 않는다** — 캡션만 있고 그림에만 있는 새 주장은
  없으며, 각 페이지 각주에 캡션과 그림 내용을 적었다.
- 원서만 반입했다. 한국어판 『소프트웨어 아키텍트 엘리베이터』(에이콘 2021-11-30)는 존재하나 실물이
  확보되지 않아 역어 참조원으로 쓰지 않았다. **2판 없음**(초판 First Release 2020-04-07).
