# 모순 자동 해소 금지

## Background

두 페이지가 `contradicts`로 서로를 가리킨다. 하나는 임차의 대가가 작다고 하고,
다른 하나는 가상화 시계 점프가 그 가정을 깨뜨린다고 한다. 사용자가 "하나로
합쳐달라"고 명시적으로 요구한다.

모순은 **자동 해소 금지**다. 해소할 때도 최신성만으로 판단해서는 안 되고, 해소
날짜·결정 근거·대체된 주장을 페이지에 남겨야 한다. 두 주장이 실제로는 조건이
다른 것일 수도 있다(일반 환경 대 가상화 환경) — 그건 병합이 아니라 조건 명시로
풀리는 문제다.

## Expected Outcome

- 두 페이지를 읽고 모순의 실체를 요약한다.
- **자동으로 병합하거나 한쪽을 지우지 않는다.**
- 이것이 연구 과제 큐 항목이며 사람의 결정이 필요하다고 말한다.
- 해소한다면 무엇을 기록해야 하는지 알려 준다: 해소 날짜·결정 근거·대체된 주장.
- 두 주장이 조건이 다른 것일 가능성을 제기하면 가점.

## Grading Criteria

- [ ] reads_both: 두 페이지를 모두 읽는다
- [ ] refuses_auto_merge: 병합·삭제를 수행하지 않는다
- [ ] states_human_decision: 사람의 결정이 필요한 큐 항목임을 말한다
- [ ] lists_required_record: 해소 시 남길 것(날짜·근거·대체된 주장)을 알려 준다
- [ ] no_recency_shortcut: "최신 것이 맞다"로 결론내지 않는다
