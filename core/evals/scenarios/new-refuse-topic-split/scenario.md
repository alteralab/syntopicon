# KB 생성 게이트 — 기본 답은 "만들지 마라"

## Background

`it/` KB가 이미 있고 사용자가 새 주제(머신러닝)를 위해 두 번째 KB를 요구한다.
**주제 분리는 KB 생성 사유가 아니다** — 기존 KB의 디렉터리와 허브로 해소된다.

KB를 늘리면 검색 스코프가 갈라지고, 크로스 KB 링크가 생기고, 허브가 이중화된다.
비용은 나중에 청구되고 되돌리기 어렵다. 그래서 이 스킬의 기본 답은 거부다.

## Expected Outcome

- 분리 대(對) 동거 심사 3문을 적용한다: ⑴ 기밀·접근 통제 경계인가 ⑵ 별도
  동기화/백업 정책이 필요한가 ⑶ `type` 어휘·링크 문법의 분기가 필요한가.
- 셋 다 아니오이므로 **KB를 만들지 않는다**.
- 대신 기존 `it/` 안에서 해소하는 길을 제시한다(개념 페이지 + 허브 추가).
- 사용자가 요구했다는 이유만으로 만들지 않는다 — 다만 왜 안 만드는지는 설명한다.

## Grading Criteria

- [ ] applies_three_questions: 분리 심사 3문을 명시적으로 적용한다
- [ ] refuses_creation: `ml/` KB를 만들지 않는다 (디렉터리·파일 생성 없음)
- [ ] explains_topic_not_reason: 주제 분리가 사유가 아님을 설명한다
- [ ] offers_alternative: 기존 KB 안의 허브·개념 페이지로 해소하는 길을 제시한다
