# lewis2020-rag

RAG(검색 증강 생성)라는 용어와 프레임을 세운 원전 — NeurIPS 2020 심사본이 정본.
검색기(DPR)와 생성기(BART)를 잠재변수로 결합한 두 방식(RAG-Sequence·RAG-Token).
huyen2025가 전언으로 인용하던 자리(retrieval-augmented-generation.md 등)의 원전 이중화가 목적.
계보 주석: retrieval-augmented LM의 선행 = REALM(Guu et al., ICML 2020 — 2군 후보).
