하나의 질문: **언어 모델링은 수많은 ML 알고리즘 중 하나일 뿐인데, 왜 그것만 ChatGPT를 낳은
규모 확대의 중심에 설 수 있었는가.**

## 지도 학습의 병목

- 저자가 스스로 던지는 질문 — **언어 모델링은 많은 ML 알고리즘 중 하나일 뿐이다. 객체 탐지·토픽
  모델링·추천 시스템·일기 예보·주가 예측 모델도 있다. 언어 모델을 ChatGPT 순간을 만든 규모 확대
  접근의 중심에 놓이게 한 특별한 점은 무엇인가** (1장, p.6).[^huyen2025]
- 답의 축은 훈련 방식이다 — **언어 모델은 자기지도(self-supervision)로 훈련될 수 있는 반면 다른
  많은 모델은 지도(supervision)를 요구한다. 지도는 레이블된 데이터로 ML 알고리즘을 훈련하는
  과정을 가리키는데, 레이블된 데이터는 얻는 데 비싸고 느릴 수 있다. 자기지도는 이 데이터 레이블링
  병목을 넘어서서 모델이 배울 더 큰 데이터셋을 만들도록 도와, 사실상 모델이 규모를 키울 수 있게
  한다** (1장, p.6).[^huyen2025]
- 지도의 절차 — **지도에서는 모델이 배우기를 원하는 행동을 보여 주는 예를 레이블한 뒤 그 예로
  모델을 훈련한다. 훈련이 끝나면 모델을 새 데이터에 적용할 수 있다. 예컨대 사기 탐지 모델을
  훈련하려면 각각 "사기"나 "사기 아님"으로 레이블된 거래 예를 쓴다** (1장, p.6).[^huyen2025]
- 2010년대의 성공이 여기 있었다 — **2010년대 AI 모델의 성공은 지도에 있었다. 딥러닝 혁명을 연
  모델인 AlexNet(Krizhevsky et al., 2012)은 지도 학습이었다. ImageNet 데이터셋의 100만 장이 넘는
  이미지를 "car"·"balloon"·"monkey" 같은 1,000개 범주 중 하나로 분류하도록 훈련되었다** (1장,
  p.6).[^huyen2025]
- 비용이 어디서 터지는가 — **한 사람이 이미지 하나를 레이블하는 데 5센트가 든다면 ImageNet용
  이미지 100만 장을 레이블하는 데 50,000달러가 든다. 레이블 품질을 교차 확인하려고 사람 둘이 각
  이미지를 레이블하게 하면 비용은 두 배가 된다. 세상은 1,000가지보다 훨씬 많은 사물을 담고 있으므로
  더 많은 객체를 다루도록 모델의 능력을 넓히려면 더 많은 범주의 레이블을 더해야 한다. 100만
  범주까지 키우면 레이블링 비용만 5,000만 달러로 늘어난다** (1장, p.7).[^huyen2025]
  - 각주의 실측 단가 — **실제 데이터 레이블링 비용은 과제의 복잡도, 규모(더 큰 데이터셋은 통상
    건당 비용이 낮다), 레이블링 서비스 제공자 등 여러 요인에 따라 다르다. 예컨대 2024년 9월 기준
    Amazon SageMaker Ground Truth는 50,000장 미만을 레이블할 때 이미지당 8센트를, 100만 장을
    넘을 때는 이미지당 2센트만 청구한다** (1장, p.7 각주 5).[^huyen2025]
- 비용은 과제마다 다르다 — **일상 사물을 레이블하는 일은 대부분의 사람이 사전 훈련 없이 할 수
  있어 비교적 싸게 된다. 그러나 모든 레이블링 과제가 그렇게 단순하지는 않다. 영어–라틴어 모델을
  위해 라틴어 번역을 만드는 것은 더 비싸다. CT 스캔이 암의 징후를 보이는지 레이블하는 것은
  천문학적일 것이다** (1장, p.7).[^huyen2025]

## 자기지도가 푸는 것

- 기제 (1장, p.7):[^huyen2025]

  > In self-supervision, instead of requiring explicit labels, the model can infer labels from
  > the input data. Language modeling is self-supervised because each input sequence provides
  > both the labels (tokens to be predicted) and the contexts the model can use to predict
  > these labels.

- 저자가 든 실물 — 문장 "I love street food."는 언어 모델링을 위한 훈련 표본 여섯 개를 준다
  (1장, p.7, Table 1-1):[^huyen2025]

  | 입력 (맥락) | 출력 (다음 토큰) |
  |---|---|
  | `<BOS>` | `I` |
  | `<BOS>, I` | `love` |
  | `<BOS>, I, love` | `street` |
  | `<BOS>, I, love, street` | `food` |
  | `<BOS>, I, love, street, food` | `.` |
  | `<BOS>, I, love, street, food, .` | `<EOS>` |

- 그 표의 두 표식 — **`<BOS>`와 `<EOS>`는 시퀀스의 시작과 끝을 표시한다. 이 표식들은 언어 모델이
  여러 시퀀스를 다루는 데 필요하다. 각 표식은 통상 모델이 하나의 특수 토큰으로 취급한다. 시퀀스
  종료 표식은 특히 중요한데, 언어 모델이 응답을 언제 끝낼지 알도록 돕기 때문이다** (1장,
  p.7).[^huyen2025]
- 헷갈리기 쉬운 구분 — **자기지도는 비지도(unsupervision)와 다르다. 자기지도 학습에서 레이블은
  입력 데이터로부터 추론되고, 비지도 학습에서는 레이블이 아예 필요 없다** (1장,
  p.8).[^huyen2025]
- 그래서 규모가 열린다 — **자기지도 학습은 언어 모델이 어떤 레이블링도 없이 텍스트 시퀀스에서
  배울 수 있다는 뜻이다. 텍스트 시퀀스는 책·블로그 글·기사·레딧 댓글 어디에나 있으므로 방대한
  훈련 데이터를 구성할 수 있고, 이는 언어 모델이 규모를 키워 LLM이 되게 한다** (1장,
  p.8).[^huyen2025]

## large의 기준은 옮겨 간다

- 용어의 지위부터 — **LLM은 과학적 용어라 하기 어렵다. 언어 모델이 얼마나 커야 "large"로
  여겨지는가? 오늘 큰 것은 내일 작다고 여겨질 수 있다** (1장, p.8).[^huyen2025]
- 척도 — **모델의 크기는 통상 파라미터 수로 잰다. 파라미터(parameter)는 훈련 과정을 통해 갱신되는
  ML 모델 안의 변수다. 일반적으로, 늘 참인 것은 아니지만, 모델이 파라미터를 더 많이 가질수록
  원하는 행동을 학습할 능력이 더 크다** (1장, p.8).[^huyen2025]
  - 각주의 단서 — **학교에서는 모델 파라미터가 모델 가중치와 편향을 모두 포함한다고 배웠지만,
    2025년 저술 시점에 우리는 대개 모든 파라미터를 가리키는 데 모델 가중치라는 말을 쓴다** (1장, p.8 각주
    7).[^huyen2025]
- 기준이 옮겨 간 실물 — **OpenAI의 첫 GPT(generative pre-trained transformer) 모델이 2018년 6월에
  나왔을 때 그것은 1억 1,700만 파라미터였고 그것이 크다고 여겨졌다. 2019년 2월 OpenAI가 15억
  파라미터의 GPT-2를 내놓자 1억 1,700만은 작다고 여겨지는 쪽으로 강등되었다. 이 책의 집필 시점
  기준 1,000억 파라미터 모델이 크다고 여겨진다. 언젠가 이 크기도 작다고 여겨질 것이다** (1장,
  p.8).[^huyen2025]
- 파라미터 수 하나로 규모를 말할 수 없다는 것은 2장이 다시 다룬다 — 저자는 파라미터 수·훈련 토큰
  수·FLOP 수 세 가지가 각각 학습 능력·학습량·훈련 비용의 대리 지표라고 정리하고, 희소 모델에서는
  파라미터 수 자체가 오해를 부른다고 덧붙인다 (2장, p.71).[^huyen2025] 그쪽은
  [모델 규모의 세 수치](../concepts/model-size-and-scale.md)가 맡는다.

## 왜 큰 모델이 데이터를 더 요구하는가

- 저자가 당연시되는 질문으로 꺼낸다 — **더 큰 모델은 배울 능력이 더 크고, 따라서 성능을 최대화하려면
  더 많은 훈련 데이터가 필요하다. 작은 데이터셋으로 큰 모델을 훈련할 수도 있지만 그것은 컴퓨트
  낭비다. 그 데이터셋에서라면 더 작은 모델로 비슷하거나 더 나은 결과를 얻을 수 있었을 것이다**
  (1장, p.8).[^huyen2025]
  - 각주에 붙은 반직관의 해소 — **더 큰 모델이 더 많은 훈련 데이터를 요구한다는 것은 반직관처럼
    보인다. 모델이 더 강력하다면 배울 예가 더 적어도 되지 않는가? 그러나 우리는 같은 데이터를 써서
    큰 모델이 작은 모델의 성능을 따라잡게 하려는 것이 아니다. 우리는 모델 성능을 최대화하려는
    것이다** (1장, p.8 각주 8).[^huyen2025]
- 이 정성적 주장에 수치를 붙이는 것이 2장의 친칠라 스케일링 법칙이다 — 컴퓨트 최적 훈련에서
  **훈련 토큰 수는 모델 크기의 약 20배여야 하고, 모델 크기가 두 배가 될 때마다 훈련 토큰 수도 두
  배가 되어야 한다** (2장, p.72).[^huyen2025] 계산의 전제와 한계는
  [스케일링 법칙](../concepts/scaling-laws.md)에 있다.
