# syntopicon

md + git이 정본이고, 나머지는 전부 여기서 재생성되는 파생물이다.
전체 카탈로그는 없다 — 이 라우터에서 KB를 고르고, 그 KB의 허브나 검색으로 내려간다.
**읽기는 KB 횡단이 기본, 쓰기는 `--kb` 명시가 필수.**
