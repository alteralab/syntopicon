# currie2024

앤 커리·세라 쉬·사라 베리만의 그린 소프트웨어 입문서(초판 첫 릴리스 2024-03-08, 추천사 에이드리언 콕크로프트).
부 구분 없이 13장 — 1장 그린 소프트웨어 소개, 2장 구성 요소(탄소 회계 기본), 3장 코드 효율, 4장 운영 효율,
5장 탄소 인지, 6장 하드웨어 효율, 7장 네트워킹, 8장 더 푸른 ML·AI·LLM, 9장 측정, 10장 모니터링, 11장 공동
이익, 12장 그린 소프트웨어 성숙도 행렬, 13장 어디로 가는가. 본문 뒤는 색인(인쇄판 pp.203–219)과 저자 소개와
판권 후기(둘 다 쪽 번호 없음)다.

- **세 저자의 소속과 역할은 저자 소개(쪽 번호 없는 뒷부속)의 실측이다.** 앤 커리(Anne Currie)는 30년 가까이
  개발자·시니어 매니저·스타트업 창업자로 일했고 리눅스 재단 산하 그린 소프트웨어 파운데이션(GSF)의 커뮤니티
  의장이며 교육·컨설팅 회사 Container Solutions의 창업자다(SF 소설 Panopticon 시리즈의 저자이기도 하다).
  세라 쉬(Sarah (Chun-Wei) Hsu)는 GSF의 Green Software Course 프로젝트 의장이고 리눅스 재단과 함께 무료 온라인
  과정 "Green Software for Practitioners"(LFC131)를 냈으며, 구글 클라우드에서 분산 플랫폼을 맡은 SRE다.
  사라 베리만(Sara Bergman)은 마이크로소프트 생태계에서 백엔드를 맡은 시니어 소프트웨어 엔지니어이고 GSF의
  개인 기여자로 Software Carbon Intensity 명세와 GSF 뉴스레터에 기여했다. **장별 저자 표시는 없다** — 세 사람의
  공저이고 본문은 "we"로 말하며, 저자 개인이 드러나는 자리는 제사와 곁상자와 감사의 말뿐이다.
- 추천사는 에이드리언 콕크로프트(Adrian Cockcroft, OrionX.net; 서명은 2024년 2월 캘리포니아 샐리너스)가 썼다.
  본문은 그를 AWS의 지속 가능 아키텍처 부사장을 지낸 사람으로 인용한다(1장, p.5).
- 판권지 실측: 저작권자는 WorkingProgram Ltd.·The Writer's House LTD·Sara Bergman AS이고, 2024년 3월 초판,
  개정 이력은 2024-03-08 First Release 하나뿐이다. **크리에이티브 커먼즈 라이선스로 무료로 읽을 수 있는 판이
  따로 있다고 서문이 밝힌다**(p.xix).
- 이 KB에서 맡는 자리는 **그린 소프트웨어 축의 첫 원전(신설 축)**이다 — 1~2장 탄소 회계 기본은 L1(시효
  없음), 3~7장 효율·탄소 인지·하드웨어·네트워크와 9~10장 측정·모니터링은 L2, **8장 AI/LLM과 도구 언급은
  L3로 얇게**(2024년 조건). 4장 운영 효율은 서버 트래픽 축(부하·과부하)과, 9장 측정은 M1 ciceri2022
  측정층과, 12장 성숙도 행렬은 mccabe2024 평가 프레임워크와 교차한다.
