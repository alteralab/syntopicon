# Raft §6.4 리더 임차 — 읽기 메모

- 임차의 시작점: 리더는 자신의 하트비트에 과반이 응답한 시각을 기준으로 임차
  시계를 시작한다. 임차 길이는 선거 타임아웃에서 파생된다.
- 안전성 조건: 임차는 "선거 타임아웃 동안 새 리더가 뽑힐 수 없다"에 기대므로,
  각 노드의 시계 드리프트가 유계라는 가정이 깨지면 두 리더가 동시에 읽기에
  답할 수 있다.
- 임차 없는 대안: 읽기마다 과반 하트비트 왕복으로 리더십을 확인한다. 왕복 1회의
  지연이 추가되지만 시계 가정이 없다.
- 인수인계: 리더 교체 시 새 리더는 이전 임차가 만료될 때까지 읽기에 답하지
  않아야 한다 — 겹치는 임차가 없어야 안전하다.
