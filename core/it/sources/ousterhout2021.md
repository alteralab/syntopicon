# A Philosophy of Software Design

스탠퍼드 CS 190(소프트웨어 설계) 강의에서 자란 책. 하나의 주제를 붙든다 — **복잡성**.
복잡한 소프트웨어 시스템을 비교적 독립적으로 구현할 수 있는 모듈(클래스·메서드)로 어떻게
쪼개는가, 그리고 그 쪼개기를 판정할 잣대는 무엇인가.

설계 판단의 잣대를 만든다.
