# newman2021

샘 뉴먼의 마이크로서비스 아키텍처 구축 2판(2021-08, 초판 2015의 전면 개정 — 분량이 두 배가
됐다). 3부 16장 + 후기: I부 기초(정의·모델링·모놀리스 분해·통신 스타일), II부 구현(통신 구현·
워크플로·빌드·배포·테스트·관측·보안·회복력·스케일링), III부 사람(사용자 인터페이스·조직 구조·
진화적 아키텍트).

- 이 KB에서 맡는 자리는 **마이크로서비스 축의 첫 정본급 실무서(L2)**다. 2026-09 실측에서
  마이크로서비스를 언급하는 페이지 65건이 전부 데이터 서적(kleppmann2026·reis2022·dehghani2022)과
  percival2020의 전언이었고 1차 소스가 없었다. 정의(1장)와 분해 휴리스틱(2~3장)이 그 공백에
  들어가고, 바운디드 컨텍스트·정보 은닉의 정의는 [evans2003](evans2003.md)에, 2021년 DDD 실무
  층은 [khononov2021](khononov2021.md) 14장에 정박한다.
- **층이 장마다 갈린다.** 1~6장과 12~16장은 L2, **7장 빌드·8장 배포는 L3**(도구·플랫폼 서술 —
  얇게, 버전 조건·사건 트리거), 10장 관측과 11장 보안은 L2 원리 + 도구 L3. 12장 회복력은
  rahman2025·bronson2021·dean2013과, 13장 스케일링은 부하·트래픽 축과 교차한다.
- 원서만 반입했다. 한국어판 『마이크로서비스 아키텍처 구축(전면 개정판)』(한빛미디어 2023-06-09,
  정성권 역)은 존재하나 실물 미확보라 역어 참조원으로 쓰지 않았다.
- 아카이브 스냅샷은 출판사 PDF이고 **인쇄판 쪽 = PDF 쪽 − 26**(실측). locator는 인쇄판 쪽으로
  적는다. 텍스트 레이어 판정과 반입 재개점의 정본은 `it/archive/newman2021/_progress.yaml`이다.
