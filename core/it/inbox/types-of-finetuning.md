## 7장이 쓰는 파인 튜닝의 정의

- 장을 여는 규정 (7장, p.307):[^huyen2025]

  > Finetuning is the process of adapting a model to a specific task by further training the whole
  > model or part of the model.

  - 프롬프트 기반 방법과의 대비 — **5장과 6장은 지시·맥락·도구를 주어 모델을 적응시키는 프롬프트
    기반 방법을 논한다. 파인 튜닝은 가중치를 조정해 모델을 적응시킨다** (7장,
    p.307).[^huyen2025] 그 두 범주의 갈림은
    [모델 적응 기법](../concepts/model-adaptation-techniques.md)이 담는다.
- 무엇을 개선하는가 — **파인 튜닝은 모델의 여러 측면을 향상시킬 수 있다. 코딩이나 의료 질의응답
  같은 도메인 특화 능력을 개선할 수 있고 안전성을 강화할 수도 있다. 그러나 가장 흔히 쓰이는 곳은
  모델의 지시 따르기 능력 개선, 특히 구체적인 출력 스타일과 형식을 지키게 하는 일이다** (7장,
  p.307).[^huyen2025]

## 사전 훈련 뒤의 모든 훈련

- 경계의 확장 — **파인 튜닝은 모델 훈련 과정의 일부다. 그것은 모델 사전 훈련의 연장이다. 사전 훈련
  이후에 일어나는 어떤 훈련이든 파인 튜닝이므로 파인 튜닝은 여러 형태를 취할 수 있다** (7장,
  p.309).[^huyen2025]
- 되짚는 출발점 — **모델의 훈련 과정은 사전 훈련(pre-training)으로 시작하는데, 이는 통상 자기지도로
  이뤄진다. 자기지도는 모델이 많은 양의 레이블 없는 데이터에서 배우게 해 준다. 언어 모델에서
  자기지도 데이터는 통상 주석이 필요 없는 텍스트 시퀀스일 뿐이다** (7장, p.309).[^huyen2025]

## 자기지도 파인 튜닝 = 연속 사전 훈련

- 값비싼 데이터 앞에 값싼 데이터를 두는 순서 — **사전 훈련된 이 모델을 비싼 과제 특화 데이터로
  파인 튜닝하기 전에, 값싼 과제 관련 데이터를 써서 자기지도로 먼저 파인 튜닝할 수 있다. 예컨대
  법률 질의응답을 위해 모델을 파인 튜닝하려면, 비싼 (질문, 답) 주석 데이터로 파인 튜닝하기 전에
  가공되지 않은 법률 문서로 파인 튜닝할 수 있다. 마찬가지로 베트남어 책 요약을 하도록 모델을 파인
  튜닝하려면 큰 베트남어 텍스트 모음으로 먼저 파인 튜닝할 수 있다** (7장, p.309).[^huyen2025]
- 이름이 둘이다 — **자기지도 파인 튜닝(self-supervised finetuning)은 연속 사전 훈련(continued
  pre-training)이라고도 불린다** (7장, p.309).[^huyen2025]

## 지도 파인 튜닝과 인필링

- 자기지도 사전 훈련이 남기는 문제 — **자기지도 학습 중에 모델이 배울 수 있는 방대한 양의 데이터는
  모델에 세계에 대한 풍부한 이해를 갖춰 주지만, 사용자가 자기 과제를 위해 그 지식을 뽑아내기는
  어려울 수 있고, 모델이 행동하는 방식이 인간 선호와 어긋나 있을 수 있다. 지도 파인 튜닝은 고품질
  주석 데이터를 써서 인간의 사용과 선호에 모델을 맞춰 다듬는다** (7장, p.310).[^huyen2025]
- 데이터 형식 — **지도 파인 튜닝(supervised finetuning) 중에 모델은 (입력, 출력) 쌍으로 훈련된다.
  입력은 지시일 수 있고 출력은 응답일 수 있다. 응답은 책 요약 과제에서처럼 열린 것일 수도 있고,
  분류 과제에서처럼 닫힌 것일 수도 있다. 고품질 지시 데이터는 만들기 어렵고 비쌀 수 있는데, 특히
  사실 일관성·도메인 전문성·정치적 올바름을 요구하는 지시가 그렇다. 8장이 지시 데이터를 얻는
  방법을 다룬다** (7장, p.310).[^huyen2025] 이 단계가 실제로 무엇을 하는지는
  [지도 파인 튜닝](../concepts/supervised-finetuning.md)이 담는다.
- 인필링 — **1장에서 논했듯 언어 모델은 자기회귀적이거나 마스크드일 수 있다. 자기회귀 모델은
  앞선 토큰을 맥락으로 써서 시퀀스의 다음 토큰을 예측한다. 마스크드 모델은 앞뒤 양쪽의 토큰을 써서
  빈칸을 채운다. 마찬가지로 지도 파인 튜닝으로도 다음 토큰을 예측하도록 또는 빈칸을 채우도록 모델을
  파인 튜닝할 수 있다. 후자는 인필링 파인 튜닝(infilling finetuning)이라고도 하며 텍스트 편집과
  코드 디버깅 같은 과제에 특히 유용하다. 자기회귀로 사전 훈련되었더라도 인필링을 위해 파인 튜닝할
  수 있다** (7장, p.310).[^huyen2025]

## 선호 파인 튜닝

- **강화 학습으로 모델을 파인 튜닝해 인간 선호를 최대화하는 응답을 생성하게 할 수도 있다. 선호 파인
  튜닝은 통상 (지시, 이긴 응답, 진 응답) 형식을 따르는 비교 데이터를 요구한다** (7장,
  p.310).[^huyen2025] 그 기제는
  [선호 파인 튜닝](../concepts/preference-finetuning.md)이 담는다.

## 롱컨텍스트 파인 튜닝

- 구조를 건드린다 — **모델의 컨텍스트 길이를 늘리려고 파인 튜닝하는 것도 가능하다. 롱컨텍스트 파인
  튜닝(long-context finetuning)은 통상 위치 임베딩 조정 같은 모델 구조의 수정을 요구한다. 긴
  시퀀스는 토큰의 가능한 위치가 더 많다는 뜻이고, 위치 임베딩이 그것을 다룰 수 있어야 한다** (7장,
  p.310).[^huyen2025]
- 대가 — **다른 파인 튜닝 기법에 비해 롱컨텍스트 파인 튜닝은 하기가 더 어렵다. 그 결과로 나온
  모델은 더 짧은 시퀀스에서 성능이 떨어질 수도 있다** (7장, p.310).[^huyen2025]

## Code Llama가 만들어진 경로

- 저자가 도판으로 실은 것을 서술로 옮겼다. **Llama 2 파운데이션 모델(7B·13B·34B)에서 출발해 서로
  다른 파인 튜닝 기법으로 서로 다른 Code Llama 모델을 만든 경로다(Rozière et al., 2024). 도판에서
  instruction finetuning은 지도 파인 튜닝을 가리킨다** (7장, p.310, Figure 7-1):[^huyen2025]
  - **Llama 2 → 코드 훈련(인필링 코드 훈련 포함) 500B → 롱컨텍스트 파인 튜닝 20B → Code Llama
    (7B·13B·34B)**
  - **같은 코드 훈련 500B → 파이썬 코드 훈련 100B → 롱컨텍스트 파인 튜닝 20B → Code Llama - Python
    (7B·13B·34B)**
  - **롱컨텍스트 파인 튜닝을 거친 가지에서 지시 파인 튜닝 5B → Code Llama - Instruct
    (7B·13B·34B)**
- 그 결과의 수치 — **롱컨텍스트 파인 튜닝을 써서 그들은 더 긴 코드 파일을 수용하도록 모델의 최대
  컨텍스트 길이를 4,096 토큰에서 16,384 토큰으로 늘릴 수 있었다** (7장, p.310).[^huyen2025]

## 모델 개발자와 애플리케이션 개발자

- 같은 기법을 누가 쓰는가 — **파인 튜닝은 모델 개발자와 애플리케이션 개발자 둘 다가 할 수 있다.
  모델 개발자는 통상 모델을 공개하기 전에 여러 파인 튜닝 기법으로 사후 훈련한다. 모델 개발자는
  각각 다른 정도로 파인 튜닝된 여러 모델 버전을 공개해 애플리케이션 개발자가 자기에게 가장 잘
  맞는 버전을 고르게 할 수도 있다** (7장, p.310).[^huyen2025]
- 애플리케이션 개발자 쪽 — **애플리케이션 개발자로서 당신은 사전 훈련된 모델을 파인 튜닝할 수도
  있지만, 대개는 사후 훈련된 모델을 파인 튜닝하게 될 것이다. 모델이 더 다듬어져 있고 그 지식이
  당신의 과제에 더 관련될수록 그것을 적응시키는 데 해야 할 일이 줄어든다** (7장,
  p.311).[^huyen2025]
