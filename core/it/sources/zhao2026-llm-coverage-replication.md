# zhao2026-llm-coverage-replication

**커버리지 논쟁을 언어 모델이 만든 스위트에 다시 건 재현 연구.** 회의 측
(`inozemtseva2014-coverage`)과 뮤테이션 쪽(Papadakis 등) 두 편을 대상으로 삼고,
**결론이 원 연구들과 상당히 갈린다**고 보고한다.

**이 소스가 이 KB에서 서는 자리는 각주 층이자 시대 지위다.** 2014년의 논쟁이 언어 모델
시대에 어떻게 다시 열렸는지를 보이는 자리로 두 페이지에서 인용된다.

## 지위 — 게재 레코드는 있으나 확보본은 arXiv 판이다

- **확보본 문면은 arXiv 프리프린트다**: 1쪽 좌측에 `arXiv:2607.22880v1 [cs.SE] 24 Jul 2026`.
- **같은 1쪽에 ACM 게재 블록이 인쇄돼 있다** — `Proc. ACM Softw. Eng. 3, ISSTA, Article
  ISSTA002 (October 2026), 24 pages. https://doi.org/10.1145/3832093` · `ACM 2994-970X/
  2026/10-ARTISSTA002`. 각 쪽의 러닝 풋도 같은 블록을 반복한다.
- **그래서 이 KB의 표기는 "게재 레코드는 ISSTA 2026(PACMSE 3권), 확보본은 arXiv v1"이다.**
  둘을 뭉개지 않는다.
- **이 등급에서 이 KB가 하는 것은 방향만 옮기는 것이다.** 확보본이 심사 통과본의 조판이
  아니므로 결과 표의 계수를 페이지에 박지 않고, 각 RQ 요약 상자가 말하는 **방향과 조건**만
  옮긴다.

## 무엇을 어떻게 쟀는가 — 인용할 때 함께 적어야 하는 조건

- **대상이 사람이 쓴 스위트가 아니다.** 최신 언어 모델 11종이 만든 **10만 개 넘는 테스트
  케이스**가 표본이다 (1절 기여 목록).
- **개념적 재현(conceptual replication)이라고 저자들이 규정한다** (1절) — 원 연구와 같은
  절차를 그대로 돌린 직접 재현이 아니라, 같은 연구 질문을 새 환경에 맞게 고쳐 물었다는
  뜻이다.
- **이 논문이 새로 넣은 축이 하나 있다** — 언어 모델에 넘기는 코드가 **버그가 없다고
  볼 수 있는 경우**와 **이미 버그가 들어 있는 경우**를 가른다. 이 축이 결론을 가르는
  자리다.
- **효과성을 실제 버그 검출로도 잰다** (RQ2) — 원 회의 측 연구가 뮤테이션 점수로만 잰
  자리를 실결함까지 넓혔다고 기여 목록에 적는다.

## 이 논문이 보고하는 방향

- **RQ1 요약**: 언어 모델이 만든 스위트에서는 **스위트 크기와 뮤테이션 점수의 상관이
  약하다**. 크기를 통제하지 않아도 커버리지와 뮤테이션의 상관은 약한데, **모델 사이를
  비교하는 관점(inter-model)에서만** 중간에서 강함으로 오른다.
- **RQ2 요약**: 코드가 버그 없는 상태에서 만든 스위트라면 커버리지가 실버그 검출과
  중간 정도 상관하고 일부 기준은 강하다. **그러나 대상 코드에 이미 버그가 있으면
  상관이 모든 관점에서 한결같이 약해진다** — 버그 있는 코드 위에서 잰 커버리지는 그
  버그를 잡는지에 대해 아무것도 말해 주지 않는다는 것이다.
- **크기가 지배적 교란 변수라는 증거를 거의 못 찾았다**고 초록과 1절이 적는다. **회의
  측 연구의 핵심 논거가 언어 모델 스위트에서는 재현되지 않았다는 뜻이다.**

## 반입 범위

이 런은 초록·1절·RQ1 요약 상자·RQ2 요약 상자·RQ3 앞부분을 읽었다. 페이지로 옮긴 것은
게재 레코드와 arXiv 판 표기, 표본 규모, 개념적 재현이라는 자기 규정, 그리고 RQ1·RQ2
요약 상자의 방향이다.

옮기지 않은 것: Table 8·12를 비롯한 결과 표의 상관 계수는 확보본이 arXiv 판이라 값을
옮기지 않았다. 3절 방법의 세부(모델 목록·데이터셋·프롬프트 설계)와 RQ3의 뮤테이션 쪽
결과는 뮤테이션 갈래가 반입될 때 다시 읽을 자리다.
