# namin2009-size-coverage

**커버리지가 효과성을 직접 올리는가, 아니면 스위트를 크게 만들어 간접으로만 올리는가**를
가른 논문. 답은 **둘 다 독립으로 영향을 준다**이고, 크기와 커버리지를 함께 넣은 모형이
크기만 넣은 모형보다 효과성을 더 잘 맞힌다는 것이 이 논문의 결과다.

**이 소스가 이 KB에서 서는 자리는 커버리지 논쟁의 옹호 측 극이다.** 같은 물음에 반대
답을 내는 회의 측(`inozemtseva2014-coverage`)과 `contradicts`로 묶인다.

## 무엇을 어떻게 쟀는가 — 인용할 때 함께 적어야 하는 조건

- **대상**: 주 실험은 지멘스 스위트 C 프로그램 일곱 개이고 **137~513 NLOC**으로 작다
  (Table 1, p.58). 교차 확인으로 `gzip`(C, 5,680 NLOC)과 `concordance`(C++, 966 NLOC)를
  더했다 (§5, pp.63~64).
- **스위트**: 각 프로그램마다 크기 1부터 50까지 각 크기별 100개를 **테스트 풀에서
  무작위로** 뽑아 만들었다 (§3.2, p.59). 크기 상한이 50인 이유는 그쯤이면 대상들이
  아주 높은 커버리지에 이르기 때문이라고 적는다.
- **커버리지**: ATAC으로 블록·결정·C-use·P-use 넷 (§3.2, p.59). `gzip`만 gcov의 줄
  커버리지다 (§5.2, p.65).
- **효과성은 두 가지다.** AM은 **뮤테이션 점수**(Proteum 뮤턴트를 죽인 비율)이고,
  AF는 **실제 결함 검출 비율**이다. AF를 잰 것은 `concordance` 하나뿐이고 그 결함은
  저자와 학생들이 몇 해에 걸쳐 찾아낸 **13개**다 (§5.1.2·§5.2, pp.64~65).
- **동등 뮤턴트 처리**: 테스트 풀 전체가 못 죽인 뮤턴트를 동등으로 간주했다 (§3.2·§5.2).
- **분석**: ANCOVA, 주성분 분석, r²와 Kendall 순위 상관, 선형 회귀 모형 비교(adjusted
  R²와 Bonferroni 보정 t 검정) (§4·§5.3).

## 이 논문이 스스로 그은 경계

- 7절이 **외부 타당도가 가장 심각한 위협**이라고 적는다. 언어가 둘(C·C++)이지만 C++는
  한 개뿐이고 둘이 비슷하며, 일곱 개는 최대 513 NLOC으로 작고 나머지 둘도 966과
  5,680 NLOC이다. **더 큰 프로그램으로 넘어가지 않을 수 있다**고 저자들이 직접 쓴다.
- 무작위 선택만 썼기 때문에 **실제 스위트 구성 방법에는 덜 직접 적용된다**고 적는다.
- 4.4절이 **대상마다 행동이 뚜렷이 갈렸다**고 보고한다. `schedule2`는 상관이 늘 낮았고
  `schedule`은 크기가 커질 때 오르내렸다. 저자들이 이유를 모른다고 쓰고, **연구자마다
  다른 대상과 크기 범위를 쓰면 다른 결론에 이르기 쉽다**고 예고한다.
