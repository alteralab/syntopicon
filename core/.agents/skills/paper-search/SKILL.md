# paper-search

**후보를 내는 데까지가 이 스킬이다.** 고르는 것은 사람이고(PLAN §4.4-1: 넣을 가치의
판단은 스크립트화 불가), 반입은 kb-ingest가 한다. 여기서 판정하는 것은 "이것이 들일
자격이 있는가"뿐이다.

사용자가 논문을 직접 지목했으면 이 스킬은 필요 없다. **에이전트가 조달할 때** 근거
없는 선택을 막는 것이 존재 이유다.

## 저장소 위치 확정 (cwd 독립 — 최초 1회)

```sh
cd "$(dirname "$(dirname "$(dirname "$(realpath "${CLAUDE_SKILL_DIR:-$HOME/.claude/skills/paper-search}")")")")"
```

## 1. 공백부터 찾는다 [KB에게 묻기]

무엇이 필요한지는 KB가 안다. 주제를 떠올려 검색하지 말고 **출처 없는 개념**을 찾아라.

```
uv run --group index tools/ksearch.py "<개념>"          # 그 낱말이 이미 쓰이나
uv run tools/edges.py neighbors <관련페이지> --depth 2   # 그 축이 무엇과 이어지나
```

찾는 것은 **페이지가 이미 이름을 쓰는데 출처가 없는 자리**다. 실측 사례: 카프카
페이지들이 "래프트(raft)"와 쿼럼을 말하는데 합의 축에 소스가 하나도 없었고, 검색으로
잡히는 "합의"는 킴벌의 agreement(뜻이 다른 낱말)뿐이었다. 그 공백이 Raft 논문을
불렀다.

공백이 없으면 **후보를 내지 않는다.** 좋은 논문이라서 넣는 것이 아니라 빈 자리가
있어서 넣는다.

## 2. 후보 탐색 [웹]

WebSearch·WebFetch를 쓴다. **전용 도구는 없다** — 손으로 돌려 반복 패턴이 실측되면
그때 tools/로 내린다(원칙 5: 실측 전 선제 구축 금지).

원전을 찾을 때는 개념 이름 + "original paper" 또는 그 개념을 만든 시스템 이름으로
간다. 서베이가 먼저 잡히면 그 서베이의 참고 문헌에서 원전을 역추적한다.

## 3. 자격 판정 4문 [판단]

**넷 다 예여야 후보가 된다.** 하나라도 애매하면 후보로 올리되 애매한 지점을 명시하고,
판단을 사람에게 넘긴다.

### ⑴ 원전인가

그 개념을 처음 세운 논문인가. 서베이·재해설·후속 개선은 원전이 아니다. 원전이
있는데 2차 문헌을 들이면 KB가 전언을 인용하게 된다.

예외: 원전이 접근 불가하거나(유료·소실) 후속 논문이 정본 지위를 얻은 경우. 그때는
소스 메타에 그 사정을 적는다.

### ⑵ 심사를 거쳤나

축마다 최상위가 다르다. 이 KB가 실제로 인용해 온 곳을 기준으로 한다.

| 축 | 최상위 |
|---|---|
| 시스템·데이터베이스 | SOSP, OSDI, VLDB, SIGMOD, USENIX(ATC·NSDI·FAST), EuroSys |
| 정보 검색·RAG | SIGIR, CIKM, ECIR |
| 자연어·LLM | ACL, EMNLP, NAACL, ICLR |
| 기계학습 일반 | NeurIPS, ICML, ICLR |

**주의**: 이 KB의 AI 축은 검색·임베딩 쪽이라 SIGIR과 ACL 계열이 주무대다. ICML은
방법론·이론 중심이라 지금까지 인용 0건이다. "AI 논문이니 ICML"은 오판이다.

**arXiv는 예외가 아니라 상수다.** LLM 관련 결과는 학회 심사를 기다리면 1~2년 늦고,
이 KB의 PLAN이 이미 arXiv를 다수 인용한다. 규칙은 둘이다:

- 심사 통과본이 나왔으면 **그쪽을 소스로 삼는다**(arXiv v1이 아니라 학회 버전).
- 프리프린트 단계면 소스 메타에 **미심사임을 명시**하고, 그 논문에서 온 claim은
  본문에 `#hypothesis`를 붙일지 판단한다.

### ⑶ 기존 축에 닿나

1단계에서 찾은 공백에 실제로 들어맞는가. "언젠가 쓸모 있을 것 같다"는 사유가 아니다.
반입 후 어느 페이지를 개정하게 될지 말할 수 있어야 한다.

### ⑷ 오픈액세스인가

archive/에 넣을 PDF의 출처가 깨끗한가. 유료 저널의 유출본은 넣지 않는다. 저자
개인 페이지·기관 리포지터리·학회 공개본을 우선한다.

접근 불가면 후보에서 빼되, 그 사실을 보고한다 — 공백은 여전히 남아 있으므로 다른
논문으로 메울지 판단해야 한다.

## 4. 후보 제시 [사람에게]

후보마다 이렇게 적는다. 판정을 숨기지 말고 근거를 보여 준다.

```
제목 (저자, 연도, 학회)
- 메우는 공백: <어느 페이지의 무엇이 출처가 없는가>
- 4문: 원전 ✓ / 심사 ✓ USENIX ATC 2014 / 축 ✓ 카프카 KRaft·주키퍼 / 오픈 ✓ usenix.org
- 반입하면 개정될 페이지: <목록>
- URL: <스냅샷에 쓸 안정 주소>
```

애매한 항목은 `?`로 두고 무엇이 애매한지 적는다. **자기 판단으로 반입하지 않는다** —
사용자가 고른 뒤 kb-ingest로 넘긴다.

## 역방향

kb-ingest 1단계에서 "논문인데 사용자가 지목하지 않은" 경우 이 스킬이 불린다.
반대로 이 스킬은 반입을 하지 않는다 — 후보와 URL을 주고 끝난다.
