# 첫 KB — 게이트를 생략하는 유일한 경우

## Background

구축이 막 끝난 상태다. 저장소에 KB가 **하나도 없고** 루트 라우터도 "아직 없다"고
말한다. 이 상태에서는 분리 심사가 무의미하다 — 비교할 기존 KB가 없다.

이 시나리오가 재는 것은 **게이트를 상황에 맞게 건너뛰는가**다. "기본 답은 만들지
마라"를 기계적으로 적용해 첫 KB까지 거부하면 시스템이 시작되지 않는다.

## Expected Outcome

- KB가 0개임을 확인한다(라우터 또는 파일시스템).
- 심사 3문을 생략하고 생성으로 직행한다.
- KB 이름·title·description을 사용자와 정하거나 합리적으로 제안한다.
- 생성은 `tools/kb-new.py`를 통한다 — 손으로 디렉터리를 만들지 않는다.

## Grading Criteria

- [ ] detects_zero_kb: KB가 0개임을 확인한다
- [ ] skips_gate: 분리 심사 3문으로 사용자를 막지 않는다
- [ ] uses_tool: 손으로 mkdir 하지 않고 kb-new 도구 경로를 쓴다(또는 쓰겠다고 제안)
- [ ] proposes_identity: KB 이름과 한 줄 설명을 정하거나 제안한다
