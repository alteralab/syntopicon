# 리더 임차와 읽기 경로 — 세션 요약 (claude 정리)

- Raft에서 선형화 가능한 읽기는 리더가 자신이 여전히 리더임을 확인해야 안전하다.
  기본 경로는 읽기마다 과반에 하트비트를 돌리는 quorum 확인이다.[Ongaro 2014, §6.4]
- 리더 임차(lease)는 이 왕복을 생략하는 최적화다: 임차 기간 동안 리더는 로컬에서
  읽기에 답한다. 대가는 시계 드리프트 한계 가정이다.[Ongaro 2014, §6.4]
- 임차와 quorum 읽기는 배타적 선택이 아니라 지연-안전성 스펙트럼의 양 끝이다.
- 가십 계열(안티엔트로피)은 합의 없이 수렴을 보장하는 다른 축이며, 갱신 누락을
  주기적 상태 교환으로 메운다.
