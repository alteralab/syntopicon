# urquhart2021

제임스 어커트의 플로 아키텍처 단행본(초판 2021-01-06). 6장 + 부록 — 1장 플로 소개, 2장 플로의
비즈니스 근거, 3장 플로 가치 사슬(워들리 매핑), 4장 2021년 스트리밍 시장 평가, 5장 플로 출현 예측,
6장 플로 미래를 위한 설계, 부록 현재 플로 시장 평가. 앞부속에 「The 10-Year Impact of the World
Wide Flow」(2034년 날짜줄의 가상 회고 기사 — 본문 실측)가 있다.

- 이 KB에서 맡는 자리는 **이벤트 스트리밍 통합의 미래상(L2/L3)**이다 — 1~3장·6장의 플로 규정·가치
  사슬·설계 원칙은 L2, **4~5장과 부록의 2021년 시장 평가·출현 예측은 L3**라 얇게 들이고 "2021년
  저술 시점" 버전 조건을 단다(2군 안에서 부패 속도가 가장 빠르다). 사건 트리거(주요 플로 표준·제품
  출현)는 재심 대상이다.
- 이벤트 기반 통합은 [bellemare2025](bellemare2025.md)·[hohpe2004](hohpe2004.md), 브로커·스트리밍은
  shapira2021·kleppmann2026, 웹훅·WebSocket·메시징 API 스타일은 [dynowski2025](dynowski2025.md)와
  교차한다. 워들리 매핑은 KB에 원전이 있는지 반입 시 실측한다.
