# Refactoring: Improving the Design of Existing Code

리팩터링이라는 말을 프로그래밍 어휘로 만든 책. 1999년 초판을 2018년에 전면 개고했고,
예제 언어가 자바에서 자바스크립트로 바뀌었다. 책의 주장은 하나다 — 설계는 미리 다
끝내는 것이 아니라 **작동하는 코드를 행동 보존 소단계로 고쳐 가며** 계속 좋아진다.

이 KB에서 **코드 품질·소프트웨어 설계 축의 원전** 하나다. 복잡성이라는 잣대를 세운
[A Philosophy of Software Design](ousterhout2021.md)이 "무엇이 좋은 설계인가"에
답한다면, 이 책은 "이미 있는 코드를 어떻게 그쪽으로 옮기는가"에 답한다. 나쁜 냄새
(bad smell) 어휘와 리팩터링 카탈로그가 그 옮기는 절차다.

- 판본은 **2판**(2018)이다. 예제는 자바스크립트로 쓰였으나 저자는 객체지향 전용이
  아니라고 명시한다.
